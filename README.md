# Air Window

Персональное веб-приложение: качество воздуха и погода на ближайшие 12 часов
для Белостока и Супрасля, чтобы выбирать время для тренировок на улице.

**Открыть:** https://artemleshko.github.io/air-window/
На Android: открыть ссылку в Chrome → меню ⋮ → «Добавить на главный экран».

## Что показывает

- **Сейчас** — последние часовые измерения PM2.5, PM10, NO₂ и O₃ на четырёх станциях GIOŚ в Белостоке
  (без усреднения между станциями), сравнение с моделью и текущая погода.
- **Советы** — тренировка, проветривание, очиститель — по согласованным порогам PM2.5.
- **Ближайшие 12 часов** — график (измерения + модель) и почасовой список: концентрация, температура,
  вероятность и количество осадков, предупреждения о скользкой дороге. Нажатие на час раскрывает детали.
- **Легенда** (кнопка «?») — шкала EAQI, пороги советов, ограничения данных.

Цвета — Европейский индекс качества воздуха (EAQI, EEA, редакция 2024).

## Откуда данные

| Источник | Что | Как попадает в приложение |
|---|---|---|
| [GIOŚ](https://powietrze.gios.gov.pl/) | Измерения станций, каждый час | GitHub Actions раз в 30 мин забирает данные через официальный API (браузер их напрямую не получит из-за ограничений CORS) |
| [Open-Meteo](https://open-meteo.com/) — CAMS Europe | Прогноз загрязнения, сетка ~11 км | Запрос прямо со страницы |
| [Open-Meteo](https://open-meteo.com/) | Прогноз погоды | Запрос прямо со страницы |

Подробности и обоснования — в [docs/DECISIONS.md](docs/DECISIONS.md).

## Как устроено

```
web/                 страница (HTML, CSS, JavaScript без сборки и библиотек)
  js/config.js       станции, точки прогноза, загрязнители
  js/eaqi.js         шкала EAQI
  js/advice.js       правила советов
  js/weather.js      осадки и предупреждения о дороге
  js/api.js          загрузка данных и офлайн-кэш
  js/chart.js        график
  js/app.js          экран
  sw.js              офлайн-режим
scripts/
  update-data.mjs    сбор измерений GIOŚ и архива
  make-icons.mjs     иконки приложения
  dev-server.mjs     локальный просмотр
tests/               проверки логики (node --test)
.github/workflows/   автоматический сбор данных и публикация
```

Ветка `data` хранит собранные данные: `latest.json` (последние 72 часа) и архив
`history/gios/ГГГГ-ММ.csv`, а также ежедневный снимок прогноза `history/forecasts/` —
чтобы позже проверить, насколько точны прогнозы.

## Локальный запуск

Нужен Node.js 20+.

```
npm test             # проверки
npm run update-data  # собрать свежие данные GIOŚ в .local-store/
npm run dev          # открыть http://localhost:8080
```

## Условия использования данных

- GIOŚ: при использовании указывается источник; текущие данные не верифицированы и могут уточняться.
- Open-Meteo: бесплатный некоммерческий доступ, данные CC BY 4.0; прогноз загрязнения — Copernicus CAMS.

Приложение — ориентир, а не медицинская рекомендация.
