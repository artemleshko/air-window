# Решения по проекту

Записываем, что и почему решили, чтобы позже не восстанавливать это по памяти.

## 2026-10-20 — первая версия

### Назначение

Несколько раз в день (около 9, 12, 15, 17 ч) быстро понять, какой воздух сейчас и в ближайшие
12 часов, и решить, когда тренироваться (шоссейный велосипед), проветривать, включать очиститель,
брать респиратор. Без уведомлений, без регистрации.

### Источники (проверено реальными запросами 2026-10-20)

- **GIOŚ** — основной источник измерений. API: `https://api.gios.gov.pl/pjp-api/v1/rest/`
  (старые адреса выведены из работы 30.06.2025). Почасовые данные, задержка 20–50 мин,
  время в ответе — местное время Варшавы. Браузер не может обращаться к API напрямую
  (CORS ограничен доменом powietrze.gios.gov.pl), поэтому данные собирает GitHub Actions.
- Станции Белостока: 609 Warszawska (фон, город), 17658 Upalna (фон, город),
  11174 42 Pułku Piechoty (фон, пригород; единственная с O₃), 11814 Piłsudskiego (у дороги).
  Ручные датчики 4025 и 28439 не используем: среднесуточные данные публикуются через 4–8 недель.
- **Open-Meteo / CAMS Europe** — прогноз загрязнения: сетка 0,1° (~11 км), обновление раз в сутки,
  реальные значения примерно на 4 дня вперёд. Работает из браузера. Некоммерческое использование
  бесплатно, CC BY 4.0. Для Супрасля модель даёт отдельный узел сетки (53,2 / 23,3).
- **Open-Meteo Forecast** — погода, в том числе вероятность осадков по часам.
- **Не используем:** Airly (бесплатный план запрещает показ данных на сайтах и в приложениях,
  цены платных — по запросу), IQAir (бесплатно — только AQI без концентраций), AccuWeather/Plume
  (нет бесплатного доступа к качеству воздуха), Sensor.Community (2 недорогих датчика рядом,
  сильно завышают при высокой влажности), прогноз IOŚ-PIB (только суточные значения, без PM2.5).
- В Супрасле нет станций GIOŚ — только модель.

### Шкала

Европейский индекс качества воздуха (EAQI) EEA, редакция 2024 (по рекомендациям ВОЗ 2021).
Цвет считается по часовой концентрации, как в Open-Meteo. В отчёте EEA для частиц упоминается
и скользящее 24-часовое среднее; мы сознательно используем часовые значения, потому что
для тренировки важна концентрация во время езды. Индексы не смешиваются с концентрациями:
на экране всегда мкг/м³.

### Советы (пороги PM2.5, мкг/м³, часовое значение)

- **Тренировка:** ≤25 — без ограничений; 25–50 — респиратор на интенсивных отрезках и в городе;
  50–90 — респиратор и спокойный темп или дома; >90 — дома. Для PM10 пороги 50/100/180.
  Озон >120 (EAQI «плохо») — пояснение: лучше утром, фильтр от частиц почти не защищает;
  озон >180 — не ниже уровня «респиратор и спокойный темп».
  25 — нынешняя суточная норма ЕС для PM2.5.
- **Окна:** ≤15 — свободно; 15–25 — коротко и интенсивно, 10–15 мин; 25–50 — 5–10 мин в самый
  чистый час ближайших 6 ч (по модели); >50 — только по необходимости.
- **Очиститель (Xiaomi 4 Compact, CADR ~230 м³/ч, квартира ~50 м³):** авто; при >25 — максимум
  на 30–45 мин (≈90% очистки за 30–45 мин).
- Опорное значение — свежее (≤3 ч) измерение Warszawska, затем Upalna, затем 42 Pułku;
  если свежих нет — значение модели с пометкой.
- Формулировки — ориентир, без утверждений «безопасно».

### Погода

Вероятность осадков (%), количество (мм) и тип (дождь, морось, мокрый снег, снег, ледяной дождь).
Предупреждения-эвристики: ≤1 °C и осадки за последние 6 ч — риск гололёда; ≥1 °C после
мороза ≤−1 °C за 48 ч — мокрая/скользкая дорога; порывы ≥14 м/с.

### Хостинг

Публичный репозиторий + GitHub Pages + GitHub Actions — всё бесплатно, без дополнительных
аккаунтов. Сайт по прямой ссылке, без пароля, закрыт от индексации (`noindex`).
Почему не закрытый репозиторий: Pages из приватного репозитория требует GitHub Pro, а сам сайт
всё равно остаётся публичным. Если понадобится пароль или более свежие данные — переезд на
Cloudflare Pages + Workers (+ Access) без изменения интерфейса.

Ограничения GitHub: расписание Actions может запаздывать на 5–30 мин; в публичном репозитории
расписание отключается после 60 дней без активности. Коммиты данных в ветку `data`, вероятно,
считаются активностью; если GitHub всё же отключит расписание, он пришлёт письмо, и включить
его обратно можно одной кнопкой во вкладке Actions.
